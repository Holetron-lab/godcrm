# Independent Excel fixtures

`poi-values.xls` and `poi-values.xlsx` were generated by Apache POI 5.5.1,
`ExcelImageProbeTest.fixture` in commit `4aa03deb375c1b1af622d7001329cec96e03b37a`,
`scripts/spikes/excel-import/src/test/java/ExcelImageProbeTest.java`.
They contain synthetic Cyrillic text, duplicate/blank headers, a leading-zero
string, boolean, date, formula `1+1` with deliberately stale cached value `7`,
two sheets and PNG/JPEG drawings. No customer data. Retained as binaries so the
runtime tests need neither Java nor the same parser to generate their inputs.
