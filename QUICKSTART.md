# GOD CRM quick start

For a new installation, follow the [self-host guide](deploy/selfhost/README.md).
It covers Docker, PostgreSQL, local secrets and initial account registration.

Use credentials you create for your own installation. Historical demo credentials
and SQLite instructions from earlier versions are obsolete.

See the [README](README.md) for the product overview and the [MCP guide](docs/MCP.md)
for connecting agents.
